## Album Review Page
This project is a simple interactive review webpage for 3 example albums. This page is built using HTML, CSS, and JavaScript. In this page users can select one of the albums, choose a rating, write a review, and submit it to display their review on the page. 

## Group Relevance
This relates to our group's final album review website because it has basic interface and interaction that users will have when reviewing albums. Since this is a simple program/page, nothing is saved, it just has simple actions that will later be implemented in our project.
