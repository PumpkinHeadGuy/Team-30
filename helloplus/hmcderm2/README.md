# login_prototype.html
A simple mock-up login page created using html. Should prompt the user to store their login details if they use a simple password manager such as the one built into Chrome. I set up a Google API client, but I couldn't figure out how to get signing in with Google working on a github website, so I settled on making a simple loginpage.
