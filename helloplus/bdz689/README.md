## Program Summary
The program recieves a Spotify access token, takes the user's album query, and request 5 most relevant albums from Spotify Web API. It then prompts the user to select an album, give a 1-5 star rating, a written review, and displays the final review back.

## How To Run
**Setup:** Install the require library using *pip install requests*.
**Execute:** Run *python app.py* in your terminal.
**Inputs:** When prompted enter an album search query, type a number (1-5) to select an album, enter a star rating (1-5), and type your written review.

## Group Project Relevance
This program provides a potential baseline for how our team will integrate Spotify's API search tools and core functionality of the album review logging.
